Не копировать локальный `.env` поверх серверного при обычном обновлении кода.

## Что запущено

Корневой Compose собирает настоящий React frontend в режиме API и Python backend
для ARM64. Caddy раздаёт React и проксирует `/api` в контейнер API.
Контейнеры: `qor-app-api-1` (healthy), `qor-app-web-1`.
API-порт 8000 не опубликован на хосте. Наружу опубликованы TCP 80 и 443.

Настройки сервера: production, домен выше, порты 80/443, CORS на HTTPS-домен,
OpenAI настроен на `gpt-6-luna`, `ALLOW_REAL_AI=false`.
Загрузка файлов открыта каждому посетителю без административного ключа.
Браузер автоматически создаёт сессию; импортированные наборы закрыты другим
сессиям. Ограничения: до 64 МиБ за запрос, 6 попыток импорта в минуту на сессию
и один обрабатываемый импорт на сервер. В этом развёрнутом архиве `ADMIN_TOKEN`
не используется.

В текущем объединённом коде репозитория по умолчанию `IMPORT_ACCESS=session`:
посетители по-прежнему загружают без ключа в собственную сессию. К лимиту
6 попыток/мин на сессию добавлен общий лимит 20/мин. Сохранён опциональный закрытый
режим `IMPORT_ACCESS=admin`: API дополнительно требует `X-Admin-Token`, совпадающий
с серверным `ADMIN_TOKEN`, а UI загрузку не выполняет. Эти изменения вступят
в силу на Oracle только после отдельного развёртывания нового архива.

## Управление на сервере

```sh
cd ~/qor-app
sudo docker compose ps
sudo docker compose logs --tail=60 api web
sudo docker compose up --build -d
```

Если после открытия сети нужно повторить получение сертификата:

```sh
sudo docker compose restart web
```

Данные находятся в томах `qor-app_qor_data`, `qor-app_caddy_data`,
`qor-app_caddy_config`. Для сохранения SQLite и сертификатов не использовать
`docker compose down -v` и не удалять эти тома.

## Обновление с Mac без GitHub-токена на сервере

Из локального репозитория после сохранения изменений в Git и получения новой main:

```sh
git pull --ff-only
git archive --format=tar.gz -o /tmp/qor-update.tar.gz HEAD
scp -i ~/.ssh/oracle_cloud /tmp/qor-update.tar.gz ubuntu@152.70.57.1:qor-app/
ssh -i ~/.ssh/oracle_cloud ubuntu@152.70.57.1
```

На сервере:

```sh
cd ~/qor-app
tar -xzf qor-update.tar.gz
sudo docker compose up --build -d
sudo docker compose ps
```

Архив содержит только закоммиченные файлы и не включает `.env`/базу.
При удалении или переименовании файлов в следующих релизах использовать чистый
каталог релиза с тем же Compose project name и томами: распаковка поверх
существующего каталога не удаляет старые файлы автоматически.

Ubuntu 20.04 — старая базовая ОС: статус её security updates/Ubuntu Pro не
проверен. Перед постоянной эксплуатацией подготовить обновление ОС отдельно,
с резервной копией и сохранением доступа. Для демо ОС в этой работе не менялась.
