## Совместимость настроек

- `OPENAI_API_KEY` / `OPENAI_MODEL` и `NVIDIA_API_KEY` / `NVIDIA_MODEL` /
  `NVIDIA_BASE_URL` поддерживаются в зависимости от `AI_PROVIDER`.
- Непустые `AI_API_KEY`, `AI_MODEL`, `AI_BASE_URL` имеют приоритет над
  настройками провайдера. Пустые значения не перекрывают настройки команды.
- Для NVIDIA нужно явно указать HTTPS endpoint; адрес OpenAI не подставляется.
- `AI_PROVIDER=disabled` по умолчанию позволяет запустить демо без ключей.
- `DATABASE_PATH` определяет точный путь SQLite; без него база располагается
  в `QOR_DATA_DIR/qor.sqlite3`. Загрузки находятся в `QOR_DATA_DIR/uploads`.
  Compose задаёт оба пути внутри постоянного volume `/data`.
- `SESSION_SECRET`, `ADMIN_PASSWORD_HASH`, `DATA_MODE`, `PUBLIC_BASE_URL`
  сохранены для совместимости с исходной спецификацией, но текущим API
  не используются. Сессии используют непрозрачные Bearer-токены, импорт —
  дополнительный `ADMIN_TOKEN`; это не система аккаунтов с паролями.
  Режим данных задаётся набором: demo синтетический, импортированные данные real.

Исходный `DATA_ENVIRONMENT.md` описывает подготовку окружения участника 2
до объединения. Для запуска всего проекта используйте команды корневого README.
`uv pip sync backend/requirements-data.lock` предназначен только для отдельного
окружения обработки данных: в общем окружении он удалит зависимости API.

## Зависимости

Общие версии Pydantic, pytest и их зависимостей совпадают в двух исходных
наборах. Runtime-зависимости обработки данных перенесены с точными версиями
из `requirements-data.lock` в `requirements-engine.txt`, который используется
Docker и шаблоном CI вместе с зависимостями API. Исходный lock с хэшами сохранён.
При изменении версий участником 2 нужно синхронно обновлять эти файлы.

## Что ещё предстоит команде

В исходной ветке нет реализаций `engine`, `importers` и `frontend`.
Их нельзя объединить до появления кода. Контракт подключения описан
в `INTEGRATION.md`; схемы для frontend — в `API.md` и `openapi.json`.
Импорт реальных файлов пока отвечает `503 integration_missing`.

Демо и его smoke проверяют работоспособность платформы, но не алгоритмы
спроса, сезонности и обработки реальных Excel. Сетевой вызов ИИ, реальная
интеграция с 1С и публикация на сервере требуют отдельных проверок.
