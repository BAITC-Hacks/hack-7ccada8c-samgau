# ИИ-помощник QOR

Раздел «ИИ-помощник» в меню: свободный вопрос, история текущего диалога, выбор товара, ссылки на разделы сайта и карточки товаров. Enter отправляет вопрос, Shift + Enter добавляет строку. Диалог живёт в памяти вкладки; смена расчёта или набора данных начинает новый диалог. Переход между разделами сохраняет текущий диалог.

## Подключение модели

В корневом `.env` задайте уже предусмотренные настройки сервера. Ключи не помещаются в `VITE_*`, код frontend или Git.

```dotenv
AI_PROVIDER=openai
OPENAI_API_KEY=<ключ проекта>
OPENAI_MODEL=<доступная вашей команде модель>
AI_RESPONSE_FORMAT=json_schema
```

Для NVIDIA используйте `AI_PROVIDER=nvidia`, `NVIDIA_API_KEY`, `NVIDIA_MODEL` и `NVIDIA_BASE_URL` выбранного OpenAI-совместимого endpoint. Если модель поддерживает только JSON mode, задайте `AI_RESPONSE_FORMAT=json_object`. Ответ всё равно валидируется Pydantic. Общие `AI_API_KEY`, `AI_MODEL`, `AI_BASE_URL` имеют приоритет над переменными провайдера.

После изменения настроек перезапустите API. Локально: `python run.py --host 127.0.0.1 --port 8000` (Python 3.12+, зависимости `backend/requirements-dev.lock` в виртуальном окружении). Frontend: из `frontend` выполните `npm ci` и `npm run dev`. Vite проксирует `/api` на порт 8000. Для Docker пересоберите API и frontend в используемой командой конфигурации; путь `/api` должен вести к сервису `api:8000`. Корневой Compose пока обслуживает отдельный каталог `deploy/web`; сам по себе он не собирает React-приложение.

`GET /api/assistant/status` показывает только готовность конфигурации, провайдера и разрешение на реальные данные. Наличие настроек не гарантирует доступность внешнего сервиса. Без ключа/модели, при тайм-ауте или невалидном ответе возвращается честно обозначенная **справка без ИИ**. Свободные общие вопросы требуют работающей модели.

При `ALLOW_REAL_AI=false` снимки с `data_mode=real` не передаются внешней модели: доступна только локальная справка. Для работы с данными компании команда явно включает `ALLOW_REAL_AI=true` в серверной конфигурации.

## Контекст и ограничения MVP

- База знаний находится в `backend/app/ai/assistant.py`, словарь `KNOWLEDGE`: названия разделов, навигация, формула заказа, проверка данных и выгрузка CSV. Её нужно обновлять вместе с интерфейсом.
- `POST /api/assistant/messages` требует bearer-сессию из `/api/sessions`. Чат использует отдельную сессию, не меняет контракты существующего расчётного клиента и не читает чужие серверные расчёты.
- Контекст — **снимок текущего экрана, присланный браузером**, а не повторный расчёт или проверенная сервером запись. Передаются склад, дата, сводка, сценарий, выбранный товар и до 40 позиций с числовыми полями. Исходные Excel, история продаж, файлы и ключи не передаются. Вопросы, последние 12 сообщений и названия товаров входят в запрос к настроенному провайдеру.
- Артикулы из вопроса и выбранный товар имеют приоритет. При большом наборе список частичный; общие счётчики описывают весь расчёт. Для отсутствующего в контексте товара следует выбрать его в поле справа.
- Ответ модели содержит текст, `destinations` из разрешённого списка и `source_skus`. Несуществующие SKU и неизвестные разделы отклоняются. Ссылки открываются только после клика пользователя. Ответ отображается текстом, без исполнения HTML.
- Это консультационный текст: модель может ошибиться. Карточки источников показывают исходные значения текущего расчёта. Чат не применяет сценарии, не создаёт заказы, не утверждает закупки и не отправляет сообщения поставщикам.
- Лимиты: вопрос 2000 символов, история 12 сообщений, до 40 товаров, сериализованный запрос до 100000 символов, ожидание модели до 15 секунд, 10 обращений в минуту на сессию. История интерфейса ограничена 80 сообщениями. Интернет-поиска и векторной базы в MVP нет.

## Проверка

- `python -m pytest backend/tests/test_assistant.py backend/tests/test_platform.py`: 26 тестов прошли.
- `cd frontend` → `npm test`: 11 тестов прошли.
- `npm run build`: TypeScript/Vite собираются; остаётся предупреждение о размере JS bundle.
- Генерация проверена через настоящий AIAdapter с `httpx.MockTransport`: схема, контекст, ссылки, ошибки провайдера, неизвестные источники. Реальный платный вызов не выполнялся: локально нет настроенных ключа и модели.
- В браузере проверены ответы локального API по навигации и выбранному ATN000343, ссылка из ответа в паспорт решения, сохранение диалога при переходах, мобильная ширина. Автотесты проверяют ограничения и запрет передачи реального снимка при выключенной настройке.

Формат ответа использует существующий совместимый адаптер и [официальную документацию OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).
