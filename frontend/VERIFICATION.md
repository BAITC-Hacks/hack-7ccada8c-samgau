# Проверка интерфейса

## Интерактивный 3D-склад

CSS 3D-сцена без новых зависимостей: выбор товара кликом по грани, поворот, фильтры, страницы по 12 секций, паспорт решения и запуск сценария. Размещение и высота секций условные; статус и количества берутся из текущих rows.

Проверено в браузере: клик по верхней грани VS510-252-18 показывает 78 шт. и открывает соответствующий паспорт; фильтр риска содержит 2 позиции, после сценария +7 дней — 7. Экран 390×844 не имеет горизонтального переполнения страницы. Production build проходит.

## Модуль ИИ-помощника

Добавлен отдельный чат по навигации и текущему расчёту. Подробности подключения и ограничения — в `docs/ASSISTANT.md`.

- Production build проходит. Все 11 frontend-тестов прошли, включая ранее не перепроверенный тест нулевого сценария.
- 26 серверных тестов чата и платформы прошли. Ответы модели проверялись через mock HTTP transport; настоящий ключ и модель локально не настроены.
- В браузере проверены ответы справочного режима от локального backend, выбранный товар, переход в паспорт решения и мобильная ширина. Справочные ответы явно помечены «без ИИ».

- Production-сборка TypeScript/Vite проходит. Сохраняется предупреждение о размере JS-chunk.
- В браузере проверены экран 1366×900 и мобильный 390×844, переход из общего поиска к ATN000343, карточка объяснения, мобильное меню, проверка данных и применение сценария +7 дней.
- Диаграмма после сценария корректно показывает 7 позиций риска вместо 2, сумма категорий — 12. Проверено отсутствие горизонтального переполнения страницы на мобильном экране.
- Проверка выполнена на синтетических данных; интеграция с backend в эту проверку не входила.

## Первоначальная реализация

Дата: 23.09.2026. Локальная Windows-среда, Node 22.16.0. Реальный backend в проверке не участвовал.

- Production-сборка `npm run build`: успешно после финальных функциональных и визуальных исправлений. TypeScript ошибок нет. Vite предупреждает о JS-chunk около 701 kB (208 kB gzip); это известная возможность дальнейшей оптимизации, не ошибка сборки.
- Первоначальный прогон `npm test`: 8 из 8 успешно. Затем добавлен девятый тест инвариантности нулевого сценария и уточнена валидация демо. Повторный запуск тестов был отклонён в запросе разрешения, поэтому полный финальный набор из 9 тестов не отмечается как пройденный.
- В браузере проверены обзор, карточка товара и шаблонное объяснение, нулевой сценарий, задержка поставки (156 → 204 для контрольного товара), возврат исходных данных, отчёт качества, пустой поиск.
- Проверено: неизвестный остаток запрещает выбор позиции; ручное изменение 156 → 168 блокирует утверждение без причины; после причины черновик утверждается, CSV скачивается.
- Проверено: при отключённом backend API-режим показывает ошибку HTTP 500 от dev proxy; на синтетические данные автоматически не переключается. Явный переход обратно на демо работает.
- Визуально проверены обычное окно браузера, ноутбук 1366×900 и мобильный viewport 390×844. Горизонтального переполнения страницы на узком экране нет; таблица имеет собственную прокрутку. Временное изменение viewport сброшено.
- Dockerfile, Nginx и Compose подготовлены. Проверка `docker info` показала, что Docker Engine на этой машине не запущен; сборка и запуск контейнера здесь не проверены.
- Публичное развёртывание, реальный ИИ, серверные сессии, права, длительное хранение черновиков и интеграция с настоящими расчётами требуют совместной проверки после подключения backend.
